# 🎓 StudySphere AI

An AI-powered student productivity platform designed to help students learn smarter and stay organized.

## ✨ Features

- 🤖 AI Study Assistant
- 📝 Smart Notes
- 📄 PDF Upload
- 🧠 AI Quiz Generator
- 📅 Study Planner
- 📊 Analytics Dashboard
- 👤 User Profile
- ⚙️ Settings
- 🌙 Dark Mode
- 📱 Responsive Design

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
